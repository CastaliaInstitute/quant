# Biopharma Data: Lineage Before Models

The research domain is biotech and pharma because clinical evidence, development stage, endpoint design, and disclosure timing are part of the market-data problem. The initial fixture was five COVID-19 vaccine Phase III readouts from 2020–2021. It has now been supplemented with Alzheimer’s, asthma, and oncology disclosures from 2019–2023. The expanded nine-disclosure/ten-trial set is still a small, hand-curated source-lineage fixture—not a representative biotech universe or a model-training cohort.

## Source plan

| Data | Source | Role | Important limitation |
| --- | --- | --- | --- |
| Trial registry records | [ClinicalTrials.gov API v2](https://clinicaltrials.gov/data-api/about-api) and its [record history view](https://clinicaltrials.gov/study/NCT04368728?tab=history) | NCT identifiers, phase, sponsor, conditions, intervention, primary outcome, posting dates, linked references, and historical versions from the record-history interface | The v2 API serves the latest record. Historical modeling needs an earlier version and its public posting date; a list of version-change modules alone is not the old content. |
| AI/ML candidate discovery | [`scripts/monitor_ai_trials.py`](../scripts/monitor_ai_trials.py) over ClinicalTrials.gov API v2 | Versioned keyword snapshot for manual screening and trend monitoring | The search finds broad healthcare AI and incidental keyword mentions. It is not a curated AI-drug cohort or a historical outcome source; see the [AI impact watch](research/ai-impact.md). |
| Linked biomedical papers | [Europe PMC REST API](https://europepmc.org/RestfulWebService) using PubMed IDs referenced by registry records | Publication dates, DOI, journal and article identity | The indexed date is not necessarily the first public disclosure or the market's first access to the result. |
| Press-release catalyst timestamps | Issuer investor-relations releases and SEC-filed exhibits | Event date and, where stated, release time | Press releases can be revised, republished, pre-announced, or released outside regular market hours. Preserve the original source and time zone. |
| Issuer filings | [SEC EDGAR submissions API](https://www.sec.gov/search-filings/edgar-application-programming-interfaces) | Accepted 8-K/6-K filing timestamps, accession numbers, and primary-document links | The API's recent submissions are useful for discovery; a present-day filing list is not itself a point-in-time event calendar or proof of first disclosure. |
| Historical OHLCV and benchmark prices | A market-data provider whose license permits the intended personal, educational, or commercial use | Price reaction, prior market context, liquidity proxies | Price access and redistribution rights are separate. Do not commit provider bars or publish them through the book without permission. Include inactive/delisted issuers. |
| Public clinical-outcome benchmark | [Clinical Trial Outcome (CTO) dataset](https://huggingface.co/datasets/chufangao/CTO) and its [paper](https://arxiv.org/abs/2406.10292) | Separately benchmark trial-outcome labels and audit phase/outcome coverage | The human-labeled subset is selected, not a representative success-rate sample; it has no market event timestamps and cannot calibrate stock returns directly. |

`data/biopharma/universe.csv` is an explicit NCT-to-issuer/CIK mapping, and `data/biopharma/public_events.csv` is a small manually sourced event table. These are seed records to be reviewed, not a complete or survivorship-free universe. `scripts/ingest_biopharma.py` fetches compact current registry records and metadata for linked papers. Add `--with-sec-filings` to also retrieve recent issuer 8-K/6-K filing metadata into the local `sec_filings.csv`; this is a discovery input, not automatic event labeling. The ClinicalTrials.gov [record history interface](https://clinicaltrials.gov/study/NCT04368728?tab=history) exposes each historical version; capture the actual older record content and its public/submission date there, then normalize it to [`trial_versions.schema.csv`](../data/biopharma/trial_versions.schema.csv). Timestamped source papers and their pre-event features belong in [`research_evidence.schema.csv`](../data/biopharma/research_evidence.schema.csv). `scripts/build_biopharma_event_panel.py` joins those as-of inputs and verified issuer readout dates to a local price export; the latest API snapshot remains marked hindsight-only.

For AI exposure curation, `scripts/monitor_ai_trials.py` saves raw keyword matches and an API-version/hash manifest under ignored `data/raw/`. Curators normalize evidence into [`ai_evidence.csv`](../data/biopharma/ai_evidence.csv), guided by [`ai_evidence.schema.csv`](../data/biopharma/ai_evidence.schema.csv), and record outcomes separately in [`ai_outcomes.csv`](../data/biopharma/ai_outcomes.csv). The first reviewed molecule-level case links rentosertib's AI-discovery attribution to its randomized Phase IIa report; it is a single candidate observation, not an AI-vs-conventional comparison. Run `python scripts/audit_ai_impact.py` to update the coverage-only report at [`_static/ai-impact-monitor.json`](_static/ai-impact-monitor.json). The AI effect questions and comparison design are documented in the [AI impact watch](research/ai-impact.md).

The history and evidence tables are point-in-time ledgers: each row needs a source URL, the timestamp it became public, and a SHA-256 hash of the archived source record. Trial snapshots preserve phase, enrollment, conditions, interventions, primary outcomes, and (when archived) study type and design fields. These are descriptors, not a score that a later result was biologically destined to succeed. Research evidence is annotated with an `evidence_class` (`preclinical`, `clinical`, or `review`) and with design, organism, assay/endpoint, population, and comparator so a reviewer can assess translation limits. A separate `evidence_role` records timing/relevance (`pre_event`, `primary`, or `secondary`); only those eligible roles enter the model, and publication time is checked against source availability. Pre-event numeric JSON is curated from a source and must use explicit units and definitions in its keys; the builder aggregates these measurements and preserves evidence-class-specific source counts. It does not derive efficacy, sentiment, or a biology score from a paper title or abstract. Keep raw archived records locally when their license allows; publish identifiers, hashes, and code when it does not. The event panel preserves record hashes so a later reader can trace each selected input.

The first source pull completed against ClinicalTrials.gov data timestamp `2026-10-14T09:00:05`: five vaccine-trial records and 52 linked article metadata records were fetched. It immediately exposed why registry dates cannot substitute for catalyst dates: the Moderna record's results were first posted to the registry in 2024, Pfizer's in 2026, and the J&J/AstraZeneca records in 2022—years after the respective 2020–2021 issuer readouts. Some linked papers are also published after the market event. This current-record extract is a lineage and feature-audit input, not a point-in-time modeling dataset. The public <a href="_static/biopharma-source-audit.json">source audit JSON</a> records event dates, registry-date lags, source URLs, and data counts without including market bars.

The event fixture now also includes Biogen/Eisai’s March 2019 aducanumab futility disclosure, AstraZeneca/Amgen’s December 2020 SOURCE asthma result, Bristol Myers Squibb’s March 2022 PIVOT IO-001 melanoma result, and Lilly’s May 2023 donanemab result. The [Biogen release](https://investors.biogen.com/news-releases/news-release-details/biogen-and-eisai-discontinue-phase-3-engage-and-emerge-trials) covers two Phase III trials; one issuer-event row links both NCT identifiers so the same BIIB return is not counted twice. The [SOURCE release](https://www.prnewswire.com/news-releases/update-on-source-phase-3-trial-for-tezepelumab-in-patients-with-severe-oral-corticosteroid-dependent-asthma-301197136.html) and [Lilly release](https://www.prnewswire.com/news-releases/lillys-donanemab-significantly-slowed-cognitive-and-functional-decline-in-phase-3-study-of-early-alzheimers-disease-301814001.html) expose precise 02:00 and 06:00 Eastern timestamps, respectively. The [BMS/Nektar release](https://news.bms.com/news/details/2022/Bristol-Myers-Squibb-and-Nektar-Announce-Update-on-Phase-3-PIVOT-IO-001-Trial-Evaluating-Bempegaldesleukin-BEMPEG-in-Combination-with-Opdivo-nivolumab-in-Previously-Untreated-Unresectable-or-Metastatic-Melanoma/default.aspx) is date-only and joint; the seed maps one BMY price series and records NKTR as a related ticker. Date-only events remain subject to a market-session ambiguity review before event returns are published.

## Data use

Run the registry and linked-publication fetch:

```bash
python scripts/ingest_biopharma.py
python scripts/ingest_biopharma.py --with-sec-filings
```

Fetch current trial/publication lineage and SEC issuer filing metadata (including SEC historical submission files):

```bash
python scripts/ingest_biopharma.py --with-sec-filings
```

The filing export contains 8-K/6-K accession metadata for the issuers in the universe. SEC acceptance times are preserved when available. Older filing rows with only a filing date are conservatively assigned end-of-day UTC availability and labeled `date_only_conservative_end_of_day_utc`, avoiding fabricated midnight precision and same-day look-ahead. At event-panel build time, counts and days since the latest filing are calculated strictly before the event feature cutoff. These are filing-activity features, not extracted trial outcomes; accession links can be reviewed for event curation. A filing timestamp does not replace verification of the first public catalyst disclosure.

For an Alpaca account with the appropriate historical feed entitlement, fetch a local adjusted daily-bar sample. The default symbols include the five issuer tickers plus SPY and XBI, used as broad-market and biotech-sector controls. Credentials are read only from shell environment variables:

```bash
export APCA_API_KEY_ID='…'
export APCA_API_SECRET_KEY='…'
python scripts/fetch_alpaca_bars.py --feed sip
```

The script requests split-, dividend-, and spin-off-adjusted bars; SIP access may require a corresponding entitlement for consolidated US coverage. Alternatively, place a licensed vendor export at `data/raw/market_prices.csv`, with columns `date,symbol,close` and optional `adjusted_close,volume`. Then build the local event panel. A sibling manifest records SHA-256 hashes of all source files, making the panel reproducible without publishing price bars:

```bash
python scripts/build_biopharma_event_panel.py
```

Raw API responses and processed price/event panels are ignored by Git. Keep the provider name, plan/feed, adjustment settings, query dates, retrieval time, and file checksum in the local manifest. For publication, the repository should contain source identifiers, code, and permissible derived summaries—not restricted raw bars. The [Alpaca historical bars API](https://docs.alpaca.markets/us/reference/stockbars) supports daily bars, historical feed selection, pagination, and corporate-action adjustments. Alpaca's customer agreement restricts reproduction or distribution without consent; a subscription is not a license to redistribute bars through the public multi-user Quant. app. Check the current agreement for your intended use.

## Event-time discipline

The registry's `ResultsFirstPostDate` may occur well after the trial result was first disclosed to investors. For example, a registry results entry can be posted after a company has already reported the readout. The pilot therefore uses company or institutional release dates where a source can be independently verified and retains registry and publication dates as separate fields. Registry dates are useful for reproducibility and compliance studies, but should not be mislabeled as catalyst dates.

The panel retains its transparent two-session raw return and issuer-minus-SPY/XBI comparisons, and now also fits a two-factor market model to adjusted daily returns. For each catalyst it estimates issuer return as an intercept plus SPY and XBI returns over sessions −230 through −31 (with a 30-session gap), requiring at least 120 complete pre-event observations. It reports daily alpha/betas, event-session and next-session abnormal returns, and additive CAR over [0,+1] and [−1,+1]. The panel also exposes `down_10pct_market_model_car_0_1` as a sensitivity target for the same chronological evaluator (`--target`); the raw issuer downside target remains the default. Market-model outputs are **outcomes only**, not pre-event model features. This controls broad and biotech-sector co-movement more directly than raw subtraction, but is still a compact factor model: it is sensitive to factor collinearity, estimation-window choice, event overlap, and daily timestamps. A biopharma event study using CRSP and RavenPack likewise uses factor-model abnormal returns and emphasizes mapping the public-news time to the first market session; its underlying datasets are subscription-restricted, so Quant. implements an independently reproducible version rather than claiming to replicate its estimates ([PLOS One study](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0296927)).

The event-panel builder maps a verified post-16:00 Eastern announcement time to the next available issuer session. If only a date is known, it uses the first session on or after that date and preserves the event-time precision as supplied; the resulting CAR should be interpreted as a date-level measure when release time is unverified. Every candidate feature—including market, trial, and curated research evidence—is frozen at the prior US regular-session close (16:00 America/New_York); `feature_cutoff_utc` records that boundary. Records posted after that cutoff are excluded even if they appeared before a next-morning release, because the target includes the overnight gap and the stated decision is at the prior close. Benchmark bars must cover each matched issuer session; the builder fails rather than silently dropping a control. The 16:00 cutoff assumes a regular session close; production should use an exchange calendar for holidays and early closes, intraday bars, and a documented next-executable-price convention. Trial and linked-paper fields from the latest registry snapshot are labeled `hindsight_annotation`; they are **not eligible model inputs** until archived versions show what was knowable by the feature cutoff.

The panel's `point_in_time_research_record_count` and `research_*` columns cover only records entered in the curated evidence ledger; they do not represent a complete or automated literature review. If a curator records pre-event numeric measurements in `pre_event_features_json`, the builder aggregates them as `research_numeric_<field>_median`; the walk-forward evaluator includes these numeric research fields automatically, with imputation fitted separately inside each training fold. Text remains in the record trace and is not scored. Any learned text representation would require a frozen corpus, a documented publication cutoff, source licensing review, and temporal validation. Publications can be selected after a result because it became notable, so their presence in today's registry is not proof they were known before a catalyst. Clinical-trial efficacy, regulatory success, and investor response must remain distinct targets. Sparse evidence counts indicate curation coverage—not scientific certainty.

The filing panel features (`issuer_filing_count_30d`, `issuer_filing_count_90d`, `issuer_8k_count_90d`, `issuer_6k_count_90d`, and `issuer_days_since_last_filing`) use only SEC-accepted filings before `feature_cutoff_utc`. They summarize disclosure activity, not filing contents or whether a filing contains material trial news. If the filing export is absent, these features are missing for fold-local imputation rather than incorrectly treated as zero; the panel manifest lists exactly which source files were used.

The eventual model may test pre-event volatility, trend, trial maturity and design (phase, enrollment, endpoint/condition/intervention counts), curated research context stratified by eligibility role and preclinical/clinical/review evidence class, and timestamped filing context as features for catalyst-window downside risk. Numeric biomedical evidence needs harmonized units, explicit populations/endpoints, source versions, and a predeclared aggregation; a median across incompatible assays or species would be meaningless. Trial success probability, probability of regulatory approval, and issuer price response are different estimands and should be modeled separately if pursued. The current COVID-vaccine events are clustered in time, share a pandemic-wide factor, and number too few to train or validate a general model. The five registry rows and 52 papers validate source acquisition only. Do not fit a model or claim market performance from this seed cohort.

The open CTO benchmark is a candidate *separate* trial-outcome benchmark, not a return dataset. Its authors define trial success as advancing phases for early studies and regulatory approval for Phase III, and describe an approximately 11,000-record human-labeled 2020–2024 subset. The published dataset page says that the manually annotated subset follows the paper's rule-based selection that removes easy cases; therefore its label prevalence is not a population prior for trial success and should not be copied into simulator transition probabilities. Quant. should first reproduce its benchmark under its own temporal, issuer/group-aware splits, audit all candidate features for post-outcome fields, and report results separately from event-risk or trading studies. Stock reaction still requires the event timestamp and licensed security returns.

- Oxford University announced the AstraZeneca Phase III interim result on November 23, 2020; see the [institutional release](https://www.ox.ac.uk/news/2020-11-23-oxford-university-breakthrough-global-covid-19-vaccine).
- Novavax's UK Phase III readout was distributed January 28, 2021 at 16:05 Eastern, after the regular US equity close; see the [GlobeNewswire release](https://www.globenewswire.com/news-release/2021/01/28/2166253/14446/en/novavax-covid-19-vaccine-demonstrates-89-3-efficacy-in-uk-phase-3-trial.html).
- Johnson & Johnson's ENSEMBLE Phase III interim readout was distributed January 29, 2021 at 08:00 Eastern, before the regular US equity open; see the [PRNewswire release](https://www.prnewswire.com/news-releases/johnson--johnson-announces-single-shot-janssen-covid-19-vaccine-candidate-met-primary-endpoints-in-interim-analysis-of-its-phase-3-ensemble-trial-301218035.html).
- Biogen and Eisai dated their aducanumab futility disclosure March 21, 2019; its single issuer event concerns both EMERGE (`NCT02484547`) and ENGAGE (`NCT02477800`), so it is represented once in the event table.
- Amgen/AstraZeneca’s SOURCE Phase III asthma disclosure was distributed at 02:00 Eastern on December 22, 2020; the release says the steroid-reduction primary endpoint was not met.
- Bristol Myers Squibb and Nektar dated the joint PIVOT IO-001 melanoma update March 14, 2022. The companies said the Phase III study did not meet the PFS and ORR primary endpoints; this seed maps one BMY return series and preserves NKTR as a related issuer.
- Eli Lilly’s donanemab TRAILBLAZER-ALZ 2 positive Phase III release was distributed at 06:00 Eastern on May 3, 2023.
